# Estruturas-de-Controle-em-C
Tarefas de estrutura de controle utilizando C no curso técnico de informática do Instituto Federal Catarinense campus São Bento do Sul, realizado em 01 de sep. de 2025

Esta atividade contém alguns exercícios na linguagem C, agora usando as estruturas básicas de controle: sequencia, seleção e repetição.

Este assunto já foi tratado em Portugol, o que muda é apenas os termos na nova linguagem, que antes usávamos em Português e agora na linguagem C estão em inglês.
